Performance Lab

Реальный браузерный A/B-тест на одном устройстве: одинаковые синтетические данные, одинаковый iframe, три повтора на каждом наборе. Baseline v0.3.12 фиксирован commit c349120b4a7e2f3d2ee5d3507b077032d1f50b0f; текущая версия определяется автоматически по номеру версии приложения.

Готово. Тест безопасен: исходные localStorage-данные восстанавливаются после завершения. Версия приложения и baseline определяются автоматически.
Как читать результаты: «Время до кадра» включает JavaScript и реакцию рендера до следующего кадра; «Макс. кадр» — максимальный интервал между callback requestAnimationFrame во время нагрузки. Composite Performance Index нормирован на baseline = 100: выше 100 — быстрее baseline, ниже 100 — медленнее. «Изменение» — это процент изменения индекса относительно baseline. Это воспроизводимый локальный benchmark, но он не заменяет Chrome DevTools Performance и реальный INP пользователя. Открыть приложение
