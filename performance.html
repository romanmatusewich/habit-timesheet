Performance Lab

Реальный браузерный A/B-тест: одна и та же машина, одинаковые синтетические данные, одинаковый способ загрузки, три повтора на каждом наборе. Сравнивается baseline v0.3.11 (до IndexedDB, commit f6338efdc1ec) с текущей v0.3.12 (IndexedDB). Замеры выполняются через High Resolution Time API и кадры браузера; это не Lighthouse и не теоретический расчёт.

Готово. Тест безопасен: исходные localStorage-данные восстанавливаются после завершения.
Как читать результаты: «Время до кадра» включает JavaScript и реакцию рендера до следующего кадра; «Макс. кадр» — максимальный интервал между callback requestAnimationFrame во время нагрузки. Composite Performance Index нормирован на baseline = 100: выше 100 — быстрее baseline, ниже 100 — медленнее. «Изменение» — это процент изменения индекса относительно baseline. Что действительно измеряется
Здесь измеряется реальный браузерный wall-clock time через performance.now(), а для рендер-реакции — прохождение через несколько кадров requestAnimationFrame(). Это валидно для сравнительного A/B-теста на одном устройстве. Однако это не «истинный INP»: программный element.click() не является реальным hardware/user input событием, а iframe добавляет собственные особенности планировщика. Поэтому Performance Lab показывает регрессию/улучшение нашей реализации, а Chrome DevTools Performance и реальный INP остаются отдельными источниками истины.
