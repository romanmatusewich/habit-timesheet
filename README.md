# Habit Timesheet

Личный timesheet для отслеживания времени на полезные привычки.

## Сейчас
- Dashboard
- Добавление времени
- Привычки и цели
- Статистика
- Дневной и недельный обзор
- localStorage
- PWA manifest

Проект сделан как статическое приложение без backend.

## Локальный запуск
Можно открыть index.html напрямую. Для удобной разработки в VS Code можно использовать Live Server.

## Публикация
Проект готов для GitHub Pages.
